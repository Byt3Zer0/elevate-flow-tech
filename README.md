# AI Automation Hub

Crea una Landing Page moderna, premium y minimalista para una agencia de automatización con Inteligencia Artificial. Usa React, Tailwind CSS y Lucide Icons. El diseño debe transmitir mucha confianza, estilo corporativo moderno, con un esquema de colores oscuros (fondos negros/pizarra con acentos brillantes en azul neón o morado).

La página debe estar estructurada para alta conversión con estas secciones:

Hero Section: Titular gigante e impactante, subtítulo persuasivo y un botón principal destacado de 'Agendar Consultoría'.

Barra de logos (opcional): 'Tecnologías que usamos' (OpenAI, WhatsApp, Meta, Make/n8n).

Sección de Servicios: Tres tarjetas grandes con diseño limpio (Instagram Bot, Asistente WhatsApp, Automatización Interna).

Sección de Beneficios: Destacar el ahorro de tiempo (ej. 'Ahorra 15h semanales') y el aumento de facturación.

Call to Action final: Un bloque grande invitando a la reunión.

Haz que el diseño sea totalmente responsive (perfecto para móvil) y añade animaciones suaves al hacer scroll o al pasar el ratón por las tarjetas.
